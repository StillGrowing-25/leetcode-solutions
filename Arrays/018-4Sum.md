# 4Sum

**Problem Link:** https://leetcode.com/problems/4sum/

---

# Intuition

The goal is to find all unique quadruplets whose sum is equal to `target`.

A brute-force solution would use four nested loops, resulting in `O(n⁴)` time. We can optimize this by sorting the array and fixing the first two elements, then using the **Two Pointer** technique to find the remaining two elements.

Sorting also makes it easy to skip duplicate values and avoid duplicate quadruplets.

---

# Approach

1. Sort the array.
2. Use the first loop to fix the first element `nums[i]`.
3. Use the second loop to fix the second element `nums[j]`.
4. Initialize two pointers:
   - `k = j + 1`
   - `l = n - 1`
5. Calculate the sum of the four elements.
6. If:
   - `sum == target` → store the quadruplet and move both pointers.
   - `sum < target` → increment `k`.
   - `sum > target` → decrement `l`.
7. Skip duplicate values for `i`, `j`, `k`, and `l` to ensure unique quadruplets.
8. Use `long long` for the sum to prevent integer overflow.

---

# Complexity

- **Time complexity:** `O(n³)`
  - Sorting: `O(n log n)`
  - Two nested loops + two-pointer traversal: `O(n³)`
  - Overall: `O(n³)`

- **Space complexity:** `O(1)` extra space
  - Ignoring the space required for the output and sorting implementation.

---

# Code

```cpp
class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        int n = nums.size();

        sort(nums.begin(), nums.end());

        vector<vector<int>> ans;

        for (int i = 0; i < n; i++) {
            if (i > 0 && nums[i] == nums[i - 1])
                continue;

            for (int j = i + 1; j < n; j++) {
                if (j > i + 1 && nums[j] == nums[j - 1])
                    continue;

                int k = j + 1;
                int l = n - 1;

                while (k < l) {
                    long long sum = (long long)nums[i] +
                                    (long long)nums[j] +
                                    (long long)nums[k] +
                                    (long long)nums[l];

                    if (sum == target) {
                        ans.push_back({
                            nums[i],
                            nums[j],
                            nums[k],
                            nums[l]
                        });

                        while (k < l && nums[k] == nums[k + 1])
                            k++;

                        while (k < l && nums[l] == nums[l - 1])
                            l--;

                        k++;
                        l--;
                    }
                    else if (sum > target) {
                        l--;
                    }
                    else {
                        k++;
                    }
                }
            }
        }

        return ans;
    }
};
```
